# Generative AI for Data Science Lab

Three real-world scenarios comparing how different prompting strategies change AI-generated code. Each notebook
shows a vague prompt and a detailed, context-rich prompt. Each prompt's code is tested on realistic messy data,
followed by the follow-up prompts and the final working solution.

| Notebook | Scenario |
|---|---|
| [scenario1_retail_inventory.ipynb](scenario1_retail_inventory.ipynb) | Retail inventory analysis: turnover, slow movers, stockout risk, visualizations |
| [scenario2_website_analytics_debug.ipynb](scenario2_website_analytics_debug.ipynb) | Debugging a website engagement function: bounce rate, session time, data validation |
| [scenario3_customer_segmentation.ipynb](scenario3_customer_segmentation.ipynb) | SQL segmentation query (SQLite): active top-20% spenders and their preference trends |

**Tools:** Python, pandas, NumPy, matplotlib, SQLite
